## 背景

刚入学的时候自己找教室绕了不少路，就想着做个能查的页面。没用什么框架，纯 HTML + CSS + 原生 JS，为的是搞清楚浏览器到底怎么工作。

## 做法

数据就是一个 JSON 数组，每条记录有建筑名、别名、经纬度、简介。页面加载时读进来，用一个输入框做模糊匹配。

```js
function search(keyword, places) {
  const q = keyword.trim().toLowerCase();
  if (!q) return [];
  return places.filter((p) =>
    [p.name, ...p.aliases].some((s) => s.toLowerCase().includes(q))
  );
}
```

地图部分最早想用 Leaflet，但校园平面图和真实经纬度对不上，最后改成直接用一张标注好的 SVG，坐标点写死在上面。虽然是笨办法，但准确度反而更高。

## 结果与反思

部署在 GitHub Pages 上，同届大概有几十个人用过。**最大的问题是数据维护**：建筑改了名字或者新增了楼，得手动改 JSON 再重新部署，没有后台。

如果重做，我会把数据放到一份单独的 Markdown/CSV 里，写个小脚本生成 JSON，至少改起来不用碰代码。
